# ZAN CEO Pulse

A powerful mobile dashboard app for business owners and CEOs to get a real-time pulse on their entire organization — financials, sales, operations, and team — all from one place.

## Features

### 📊 Financial Dashboard (Home)
- Revenue, Profit, Expenses & Cash Flow KPIs
- 6-month Revenue Trend chart
- Net Profit Trend chart
- Expense breakdown by category
- Financial Health Score with sub-scores (Liquidity, Profitability, Solvency, Efficiency)
- Period selector (1M / 3M / 6M / YTD / 1Y)

### 📈 Sales Dashboard
- Sales KPIs (Total Sales, New Clients, Win Rate, Avg Deal Size)
- Monthly Sales bar chart
- Sales Pipeline funnel (Prospecting → Closed Won)
- Top Customers by revenue with YoY growth

### ⚙️ Operations Dashboard
- Efficiency, On-Time Delivery, Inventory Turns, Cost per Unit KPIs
- Supply Chain status flow visualization
- Department performance vs. targets
- Inventory levels with reorder point indicators
- Prioritized action items (Critical / High / Medium)

### 👥 People & Team Dashboard
- Headcount, Retention Rate, Avg Performance, Open Positions KPIs
- Department headcount breakdown
- Workforce status (On-site / Remote / On leave)
- Top performer leaderboard
- Hiring pipeline by stage

### 🔔 Pulse Alerts
- Real-time business alerts (Critical / Warning / Info / Success)
- Filterable by type
- Unread notification badges
- Mark all / individual read functionality

## Tech Stack

- **React Native** with **Expo**
- **TypeScript**
- **React Navigation** (Bottom Tabs)
- **react-native-chart-kit** for charts
- **@expo/vector-icons** (Feather icons)
- **react-native-safe-area-context**

## Getting Started

```bash
npm install
npm run android   # Android
npm run ios       # iOS (macOS only)
npm run web       # Web browser
```
